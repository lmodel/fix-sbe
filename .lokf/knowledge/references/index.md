# References

* [FIX Simple Binary Encoding](sbe-specification.md) - The FIX Trading Community's repository for SBE, `FIXTradingCommunity/fix-simple-binary-encoding`, which holds the specification, XSDs and examples of each edition under CC BY-ND 4.0.
* [FIX SBE conformance suite](sbe-conformance-suite.md) - `FIXTradingCommunity/fix-sbe-conformance`, FIX's test suite for SBE implementations under Apache-2.0, three of whose SBE 1.0 message schemas this repository holds at the tag `v1.0`.
* [FIX Orchestra transposer](orchestra-transposer.md) - `FIXTradingCommunity/orchestra-transposer`, FIX's Apache-2.0 converters between SBE and Orchestra, whose `SBE2Orchestra10_10` and `SBE2Orchestra20_10` classes the schema's mappings follow.
