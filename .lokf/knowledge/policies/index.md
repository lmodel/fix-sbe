# Policies

* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: a person owns every contribution, an element says what the XSD says, a rule states only what the specification states, a mapping follows FIX's transposer or is absent, and FIX's words stay FIX's.
* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and the schema under Apache-2.0, the bundle under CC BY 4.0, FIX's XSDs and examples whole and unchanged under CC BY-ND 4.0, and the conformance suite's schemas under Apache-2.0.
* [Security policy](security-policy.md) - How to report a vulnerability, what this repository releases, what executes here and what holds each surface. A report goes through GitHub's private vulnerability reporting, and only the latest release receives fixes.
